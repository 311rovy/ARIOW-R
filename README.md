## Technology

This website is built with:

- Next.js
- React
- Styled Components
- Framer Motion
- Context API
- HTML Canvas

## Running locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available at [http://localhost:3000](http://localhost:3000).
